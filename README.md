# Site — будущий сайт Kenai VPN

Здесь будет сайт проекта на **WordPress**. Репозиторий пока служит местом для будущей разработки: готовой темы, плагинов и работающего сайта в нём нет.

## Планируемые разделы

1. **О сервисе** — что такое Kenai VPN и для чего он нужен.
2. **Приложение** — описание возможностей и инструкция по установке.
3. **Подключение** — понятные шаги активации и начала работы.
4. **Поддержка** — ответы на вопросы и способы связи.

Конкретные функции, дизайн и плагины будут определены на этапе разработки. WordPress потребует PHP, MySQL/MariaDB и веб-хостинг; GitHub будет хранить исходники темы и собственных доработок.

Связанные проекты: [приложение для Windows](https://github.com/pasha-tsaran/desktop_app) · [админ-панель](https://github.com/pasha-tsaran/admin-panel).
